# PHP Version Support

Snipe-IT MUST run on PHP 8.2 through 8.5. `composer.json` declares `"php": "^8.2"`, and `config.platform.php` is pinned at `"8.2"` so the lockfile stays 8.2-compatible across all contributor machines.

## Rules

- **Never use PHP 8.3+ syntax.** Typed class constants (`const array X`), `json_validate()`, property hooks, asymmetric visibility, etc. are all banned. A parse error silently drops the whole class on 8.2, so failures cascade far from the source.
- **Never bump a package to a version that requires PHP > 8.2.** The `platform.php: "8.2"` config prevents this on `composer update`, but a hand-edit of `composer.json` with an explicit `^8.3` dep would bypass that guard.
- **If `CLAUDE.md`'s auto-generated foundation section says the app runs on PHP 8.5 (or any single version), ignore it.** That line gets regenerated by `boost:update` with whatever PHP the person running `composer update` had locally. The authoritative statement is here.

## Verification

```bash
composer check-platform-reqs    # confirm nothing requires > 8.2
composer why-not php 8.2         # should show no blockers
```
