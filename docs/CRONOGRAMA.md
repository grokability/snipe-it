# Cronograma de Sprints

## Planificación General del Proyecto

El proyecto se desarrollará mediante tres sprints principales orientados a la planificación, implementación y validación de pruebas de software sobre Snipe-IT.

| Sprint   | Fecha de Entrega | Objetivo Principal                           | Entregables                                                                                      |
| -------- | ---------------- | -------------------------------------------- | ------------------------------------------------------------------------------------------------ |
| Sprint 1 | 27 de mayo       | Planificación inicial y análisis del sistema | Presentación del producto, tablero Kanban, GitHub Pages, GitHub Wiki y plan de pruebas unitarias |
| Sprint 2 | Junio 2026       | Desarrollo y ejecución de pruebas            | Casos de prueba implementados, evidencias de ejecución y automatización inicial                  |
| Sprint 3 | Julio 2026       | Validación final y documentación             | Resultados finales, métricas de calidad, cobertura y documentación completa                      |

## Hito 1

### Actividades

* Configuración del repositorio.
* Análisis de la arquitectura de Snipe-IT.
* Elaboración del plan de pruebas unitarias.
* Configuración de GitHub Projects.
* Implementación de GitHub Pages.
* Elaboración de documentación inicial.

## Hito 2

### Actividades

* Desarrollo de pruebas unitarias.
* Ejecución de pruebas.
* Corrección de incidencias encontradas.
* Integración continua mediante GitHub.

## Hito 3

### Actividades

* Validación de resultados.
* Generación de métricas.
* Elaboración del informe final.
* Preparación de la sustentación del proyecto.

## Herramientas Utilizadas

* GitHub Projects
* GitHub Issues
* GitHub Wiki
* GitHub Pages
* PHPUnit
* Docker
* Git
* Laravel
